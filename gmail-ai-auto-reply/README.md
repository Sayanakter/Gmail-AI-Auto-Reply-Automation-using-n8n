# Gmail AI Auto Reply

An n8n workflow that automatically reads incoming Gmail emails, generates AI-powered replies, and creates draft responses.

## Features

- 📧 Trigger on new Gmail emails
- 🤖 AI-generated professional replies
- 📝 Saves reply as Gmail Draft
- ⚡ Fully automated with n8n
- 🔒 Secure OAuth authentication

## Workflow

New Email
↓
Gmail Trigger
↓
AI (OpenAI/Gemini)
↓
Generate Reply
↓
Create Gmail Draft

## Tech Stack

- n8n
- Gmail API
- OpenAI / Gemini API
